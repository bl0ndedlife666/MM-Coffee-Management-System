# MM Coffee Management System

A Windows Forms (.NET 8) point-of-sale and inventory system for coffee shops, using an MS Access database.

## Features
- Login with roles (Administrator and Cashier) and hashed passwords
- Orders with sizes, discounts, payment, and receipt preview
- Recipe-based ingredient deduction and low-stock alerts
- Menu, inventory, supplier, and staff management
- Daily and weekly reports with CSV export
- Analytics charts (orders per hour, revenue per day, top items)

## Requirements
- Windows 10 or 11
- Visual Studio 2022 with the .NET desktop development workload
- .NET 8 SDK
- Microsoft Access Database Engine (x64)

## How to run
1. Clone the repository or download it as a ZIP.
2. Open CoffeeManagementSystem.sln in Visual Studio 2022.
3. Set the platform to x64 in the toolbar.
4. Close Microsoft Access if it is open, then press F5.

## Tech stack
